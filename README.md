# 🎓 Student Management System

A Python-based **Student Management System** that allows users to manage student records using CRUD operations.

The project is built using **Object-Oriented Programming (OOP)** with JSON file storage, input validation, error handling, and logging.

---

## 🚀 Features

- ✅ Add Student
- ✅ View All Students
- ✅ Search Student
- ✅ Update Student Details
- ✅ Delete Student
- ✅ JSON-based Data Storage
- ✅ Input Validation
- ✅ Email Validation
- ✅ Phone Number Validation
- ✅ Age Validation
- ✅ Activity Logging

---

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- JSON File Handling
- Regular Expressions
- Tabulate Library
- Logging Module

---

## 📂 Project Structure

```
Student-Management-System/
│
├── main.py                 # Application entry point
├── student.py              # Student class definition
├── student_manager.py      # CRUD operations logic
├── file_handler.py         # JSON file handling
├── logger_config.py        # Logging configuration
├── students.json           # Student data storage
├── student_system.log      # Activity logs
└── README.md               # Project documentation
```

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone <your-github-link>
```

### 2. Navigate to Project Folder

```bash
cd Student-Management-System
```

### 3. Install Required Package

```bash
pip install tabulate
```

---

## ▶️ How to Run

Run the application using:

```bash
python main.py
```
